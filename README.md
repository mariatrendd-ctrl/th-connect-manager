🖥️ TH CONNECT - LocalXpose Manager
O TH CONNECT é uma aplicação de interface gráfica (GUI) desenvolvida em Python, projetada para simplificar a gestão de túneis TCP através do LocalXpose. Diferente de scripts de linha de comando, o TH CONNECT oferece um painel visual intuitivo para monitorar e controlar múltiplas conexões simultaneamente.

🚀 Funcionalidades Principais
Painel de Slots Independentes: Gestão de até 10 slots de conexão simultâneos.
Controle em Tempo Real: Ativação, pausa e retomada de túneis com apenas um clique.
Monitoramento de Status: Indicadores visuais de cores para identificar rapidamente conexões online, pausadas ou vazias.
Kill Switch Global: Botão "Parar Tudo" para encerramento imediato de todos os processos ativos.
Interface Dark Mode: Design moderno e otimizado para reduzir a fadiga visual durante a operação.
🛠️ Especificações Técnicas
Linguagem: Python 3.x
Interface: Tkinter (Custom Style)
Integração: Subprocess management para controle do binário loclx.exe.
⚙️ Pré-requisitos
Para o funcionamento correto da aplicação, é necessário:

Python 3.x instalado.
LocalXpose: O executável loclx.exe deve estar localizado obrigatoriamente em: C:\loclx-windows-amd64\.
🚀 Como Utilizar
Execute o script main.py.
Insira o Endpoint do LocalXpose no campo correspondente ao slot.
Insira a Porta Local que deseja tunelar.
Clique em ATIVAR.
O status mudará para 🟢 Online assim que a conexão for estabelecida.
